## 1. 报告主线：不平衡评论分类中的表示能力与计算成本

本项目最有说服力的结果是：**在共享的数据划分下，LoRA 微调的小型解码器 LLM 以 0.28% 的可训练参数取得最高的微调指标（Qwen3.5-2B-Base macro-F1 0.942、负类 F1 0.902；Qwen2.5-1.5B 0.940 / 0.897），不训练的 Qwen3.8-27B 零样本在阈值 0.5 下与之持平（0.940）、校准阈值后给出 0.953 的测得上限，而 TF-IDF 以 1.14 秒的五折成本提供 0.854 的低成本参照。** 报告沿“TF-IDF → 预训练词向量 → 编码器微调 → 解码器 LLM 的 LoRA 微调 → 27B 零样本”的阶梯展开，回答“每一级增加的计算成本换来了什么负类识别能力”，并据此说明不同资源预算下的模型选择。

报告的价值来自统一评估、针对不平衡类别的分析，以及有实测依据的资源权衡。各章节都应服务于这条论证。

### 1.1 主结果与证据

当前核心结果来自去重后的 **7,185 条训练评论、共享 5 折、训练 seed=42、阈值 0.5**（RoBERTa-base 另有 seed 2024、7）。完整主表、两折探索、资源统计和各项评分口径统一维护在 [实验结果与评估口径](experiment_results.md)，正文重点解释四组证据：

1. **LoRA 微调的小型 LLM 取得最高微调指标。** Qwen3.5-2B-Base + LoRA 的 accuracy / macro-F1 / 负类 F1 为 0.971 / 0.942 / 0.902，Qwen2.5-1.5B + LoRA（提交模型）为 0.970 / 0.940 / 0.897；相对含否定标记的 TF-IDF，macro-F1 增加 8.79 / 8.55 个百分点，负类 F1 增加 14.97 / 14.53 个百分点；可训练参数 620 万 / 436 万（0.28%）。更强的总体结果同时伴随少数类表现的更大改善，是摘要、主结果段和结论的共同记忆点。
2. **零样本 27B LLM 给出任务上限，LoRA 模型以更低推理成本达到其默认阈值水平。** Qwen3.8-27B 不训练、不看标签，阈值 0.5 下 macro-F1 0.940、ROC-AUC 0.988；用训练标签校准阈值后 0.976 / 0.953（嵌套 0.975 / 0.951）。其单模型推理 121.8 s，是 Qwen2.5-1.5B LoRA（14.06 s）的 8.7 倍、Qwen3.5-2B LoRA（8.82 s）的 13.8 倍。
3. **收益来自任务微调。** 同一 RoBERTa-base 微调比冻结特征 + LR 高 7.49 个百分点，同一 Qwen2.5-1.5B 的 LoRA 微调比冻结末 token + LR 高 11.34 个百分点；RoBERTa-base 三个 seed 的 macro-F1 0.923 / 0.923 / 0.924（标准差 0.001）说明协议稳定。
4. **低成本基线与词向量对照完成阶梯。** 含否定标记的 TF-IDF + LR 在 CPU 上 1.144 秒完成 5 折向量化与拟合，macro-F1 0.854，比无否定标记版本高 0.86 个百分点；GloVe 初始化使 BiLSTM 的 macro-F1 从 0.824 增至 0.860（3.64 个百分点）。

### 1.2 用资源成本解释模型选择

资源图建议使用横轴为对数刻度的训练时间、纵轴为 macro-F1 的散点图，按硬件分组标注。本机 MPS 完整运行的累计计时：TF-IDF 向量化与拟合约 1.14 秒，GloVe + BiLSTM 约 215 秒（GloVe 加载另计约 35 秒），RoBERTa-base 约 57 分钟；Colab L4 bf16：RoBERTa-base 10.6 分钟，DeBERTa-v3-base 21.5 分钟，Qwen2.5-0.5B LoRA 23.3 分钟，Qwen2.5-1.5B LoRA 80.3 分钟；Colab A100：Qwen3.5-2B-Base LoRA 44.0 分钟，Qwen3.8-27B 零样本 0 训练、加载 1.6 分钟、1,851 条推理 121.8 秒。图注采用实验结果页中的计时定义，区分单模型推理与五折集成、进程 RSS 与 GPU 峰值显存。

讨论按使用场景展开：频繁重训或 CPU 预算紧张时，TF-IDF 是现成选择；有一块 24 GB GPU、重视负类识别时，Qwen2.5-1.5B + LoRA（L4，开梯度检查点，80.3 分钟，峰值显存 4.1 GB，0.940）给出该预算下最高的微调指标，DeBERTa-v3-base（21.5 分钟，7.0 GB，0.934）是省时的替代；有 40 GB GPU 时，Qwen3.5-2B-Base + LoRA（A100，44.0 分钟，峰值显存 27.6 GB，0.942）再高 0.25 个百分点；完全没有标注预算时，27B 零样本在阈值 0.5 下已达 0.940。GloVe + BiLSTM 与冻结特征 + LR 提供检验预训练初始化和任务微调作用的中间层对照。

## 2. 写作时保持一致的评估口径

详细协议和数据统计见 [实验结果](experiment_results.md)。正文方法节与表注至少交代以下内容：

- **数据基数：** 原始训练集 7,401 条，按完整评论文本去重后 7,185 条；主结果使用去重数据。原始正类比例为 85.38%，去重后为 85.40%，以 macro-F1 和负类指标补充 accuracy。训练 / 测试重叠情况作为数据描述，测试预测统一由模型生成。
- **完整与部分运行：** 主表统一使用共享的完整 5 折。带 `_f0-1`、`partial=True` 的运行只覆盖其中的折 0、1，用于配置探索；它不是另一套完整的 2 折交叉验证。比较默认配置时也提取相同两折。
- **折与 seed：** 主表训练 seed 为 42，`±` 表示各折得分的总体标准差（`ddof=0`）。RoBERTa-base 另以 seed 2024、7 在 Colab L4 重复，三个 seed 的 macro-F1 为 0.923 / 0.923 / 0.924（标准差 0.001），accuracy 标准差 0.0004；正文分别报告折间变动与 seed 间变动。
- **指标汇总：** 折均值与汇总全部 OOF 预测后计算的 pooled 指标分别命名，尤其不能混用 ROC-AUC。阈值 0.5 的主表与经选择阈值的结果分开。
- **阈值：** 最终阈值在全部 OOF 上选择。`oof_at_threshold` 在同一组 OOF 上选择并评分；`oof_at_threshold_nested` 在其余折 OOF 上选择阈值，再应用到当前折，是阈值选择的交叉估计；checkpoint 选择的稳定性由 `*_last` 对照给出。
- **Checkpoint：** 神经模型使用留出折选择 macro-F1 最优的 checkpoint，记录最优与最后时点的 OOF 预测和指标。PLM 的 `*_last` 对应固定轮数末端，词向量模型对应早停时刻。三种口径（最优 checkpoint / 最后 checkpoint / 嵌套阈值）的 macro-F1 在 RoBERTa-base 上为 0.923 / 0.921 / 0.922，在 Qwen3.5-2B 上为 0.942 / 0.938 / 0.941，正文以此说明结论对选择规则稳定。
- **最终提交：** 当前提交为 `qwen2.5_1.5b_lora16_len256_seed42` 的 5 个折模型测试概率平均，再应用 OOF 阈值 0.45；测试集无标签，报告以 CV 指标描述验证表现，以预测正类比例 86.17%（训练先验 85.40%）描述输出。

描述性统计与结论对应：疑似标签分歧以 `results/analysis/label_noise_candidates.csv`（92 条零样本 LLM 高置信分歧，其中 57 条三个监督模型 OOF 一致）为起点，经人工复核后写成案例；噪声率等总体判断以复核样本为依据。

### a) 从研究设定推导方法选择

先定义本项目：英文商品评论的文档级二分类，输入为文本，输出为负面 / 正面标签。样例中的鞋服和交易用语可作为内容观察；具体数据子域、原始星级与标签转换规则，需要数据说明支持后再写成事实。

综述先用三个轴组织材料，再按方法家族串联论文：

| 比较轴 | 两端设定 | 与本项目的关系 |
|---|---|---|
| 监督信息 | 有标签监督学习 / 无标签或弱监督学习 | 当前训练数据有标签；h) 讨论无标签目标域 |
| 类别空间 | 封闭类别集 / 开放集或包含未知类别的场景 | 当前标签为 0/1；酒店评论可能需要处理中性、混合或未知情感 |
| 领域关系 | 同域评估 / 跨域迁移 | 当前为商品评论；h) 延伸到酒店评论 |

方法链可采用“词袋与线性模型 → 静态词向量与 CNN/RNN → 预训练语言模型 → 领域适应与弱监督”。每组论文说明它解决什么问题、依赖什么监督信号，以及与本项目的联系。文档级、句子级和方面级是另一条任务粒度轴，单独解释，避免与开放集混为一谈。

课程 a(2) 要求快速阅读并总结数十篇论文，a(3) 要求识别 1–2 个突出的研究组，选择感兴趣的论文深入总结。保留检索关键词、数据库、时间范围和筛选标准；阅读表记录“论文 / 设定 / 方法 / 关键证据 / 本项目使用位置”，正文用代表工作串联整体认识。研究组精读可从 Bing / Zhang 的情感分析研究和 Reichart 团队的领域适应工作中选择，纳入前核对作者关系与论文内容。

方法选择段直接连接已有结果：TF-IDF 建立低成本参照，GloVe 对照检验预训练初始化的价值，RoBERTa / DeBERTa 检验编码器微调对少数类识别的改善，Qwen 的 LoRA 微调检验解码器 LLM 以 0.28% 可训练参数能达到的微调指标（macro-F1 0.942 / 0.940），冻结特征 + LR 隔离任务微调的作用，Qwen3.8-27B 零样本给出不依赖标签的上限并为 h)、i) 提供方法依据。每个模型对应一个明确的问题。

### b) 预处理服务于各自的表示方式

- **TF-IDF：** 使用 1–2 gram、子线性 TF、`min_df=2`、`max_df=0.95`，保留否定相关文本信号，并以同配置有 / 无否定标记的实验隔离其效果。
- **GloVe：** 小写、拆分标点与缩写；每折训练词表中，GloVe 已有词出现至少 1 次即可收录，其他词要求至少 2 次；未见词映射至 `<unk>`。当前 BiLSTM 摘要中的 GloVe 初始化覆盖率约为 97.7%–97.9%，需注明是词表覆盖率。
- **预训练语言模型：** RoBERTa / DeBERTa / Qwen 均使用各自的预训练 tokenizer，保留原始文本的大小写与标点，最大长度 256，采用前 75% / 后 25% token 预算的 head+tail 截断（RoBERTa 子词长度中位数 51，截断比例 2.17%）。零样本 LLM 把同样截断后的评论放入固定提示词，读取标签词 logits。

### c) 讲清模型与实际配置

模型节围绕“输入表示 → 编码或特征提取 → 池化 / 分类 → 损失”说明计算流程。TF-IDF 配线性分类器；GloVe 分别接 BiLSTM 和 TextCNN；RoBERTa / DeBERTa 使用预训练编码器与序列分类头；Qwen 解码器在注意力投影上加 LoRA（r=16）并训练末 token 上的分类头；冻结特征行只训练逻辑回归；Qwen3.8-27B 零样本不训练，用提示词与标签词 logits 直接给出概率。关键参数从 [模型配置表](experiment_results.md) 和对应 summary 提取，包括输入长度、学习率、类权重、LoRA 秩、嵌入冻结、训练轮次和选择规则。

架构图应与实现一致，尤其是 BiLSTM 对变长序列的处理、池化与分类头。用维度标注连接各模块，并解释为什么这些结构适合本项目的比较目的。

### d) 用已开展的探索解释超参数

DistilBERT 在折 0、1 上探索学习率与类权重；随后按记录规则 `min(选定学习率, 3e-5)` 设定 RoBERTa 学习率。DeBERTa-v3（`lr=2e-5`）与 LoRA（`r=16`、`alpha=32`、`lr=2e-4`）配置为预先设定值，正文标注为“预先设定”。正文据此说明从探索到完整验证的配置选择过程。

BiLSTM 的学习率、hidden 和冻结嵌入试验也属于两折探索，正文使用默认配置的相同两折作参照。在相同折集合上描述配置差异；冻结 / 解冻涉及的机制解释作为待验证假设。

建议保留一张配置表和一至两张能解释选择的曲线。已完成、预先设定和待验证三个状态分开标注，避免将建议搜索范围写成实际搜索范围。

### e) 将报告结果对应到提交文件

### f) 让错误分析解释主结果

以相同 OOF 样本比较 TF-IDF、RoBERTa 与 Qwen2.5-1.5B LoRA，并以 Qwen3.8-27B 零样本概率作为不依赖标签的第四个参照，首先给出混淆矩阵和负类 precision / recall，再人工复核否定、转折、混合评价、领域词义、长文本和疑似标注不一致等类别；`results/analysis/label_noise_candidates.csv` 中 57 条四个模型一致反对标签的评论是疑似标注不一致类别的起点。错误类型比例交代抽样方式、复核数量及是否允许多标签。

课程 f) 要求分析测试集中的 1–2 个案例。选取包含否定、转折或混合评价的测试评论，将文本、预测概率、模型分歧和人工判断并列，并明确测试集没有官方标签。OOF 案例可补充展示“LoRA 模型正确而 TF-IDF 错误”、“零样本 LLM 与微调模型一致而标签不同”以及各模型均误判的情形。词级归因辅助观察，机制解释表述为待检验假设；涉及疑似错标时，保留原标签并记录复核依据。

若需要人工测试子集分析，可预先随机抽取 200–300 条，由三人独立标注并裁决分歧，报告抽样方案、标注准则、标注一致性（如适用于多人的 Fleiss' kappa）和结果区间。该结果是相对于人工标签的补充评估；低置信或模型分歧样本适合案例分析，不适合直接估计总体测试准确率。此项尚需实际完成后才能写入结果。

### g) 让资源表服务于模型选择

从 [实验结果](experiment_results.md) 提取完整运行的资源表。补充特征维度、参数量和内存时，分别说明其含义：TF-IDF 的维度是词表大小，GloVe 的 300 是单词向量维度，RoBERTa / DeBERTa 的 768 与 Qwen 的 896 / 1536 / 2048（Qwen2.5-0.5B / 1.5B / Qwen3.5-2B-Base）是隐层维度；其中 2048 取自 Qwen3.5-2B-Base 配置的 `text_config.hidden_size`，`runs.csv` 中该行 `feature_dim` 记为 0，需手工补入。参数量区分全模型与可训练部分（LoRA 行 0.28%–0.44%），内存按进程峰值 RSS、MPS 折末分配量和 CUDA 峰值显存分列报告，各列按其定义解释。

### h) 无标签酒店评论：明确目标域方案与验证方式

本节将商品评论的发现延伸为酒店域的迁移方案。本项目已有一条直接证据：不看任何标签的 Qwen3.8-27B 零样本在商品评论上达到 macro-F1 0.940（阈值 0.5），与微调小模型持平，因此在无标签目标域中，零样本 LLM 既是可用的起步方案，也是为微调模型生成伪标签与筛选复核样本的工具。可从词汇变化、多方面评价、文本长度和类别比例变化解释风险：例如，退货、尺码和物流词汇在酒店评论中的作用可能改变。性能结论留待目标域实验建立。

按数据预算提出可执行方案：

| 可用资源 | 方案 | 评估与选择方式 |
|---|---|---|
| 目标域无标签文本 | 源域 LoRA 模型直接迁移，与零样本 LLM（本项目中 0.940 macro-F1，不用标签）互为参照；用两者一致的高置信样本做伪标签或一致性训练 | 报告两者的预测一致率与分歧样本，对分歧样本做人工审查 |
| 少量人工标注预算 | 建立目标域验证与评估样本，优先覆盖混合情感及模型分歧 | 将用于模型选择的样本与最终评估样本分开 |
| 较多无标签文本与可靠初始模型 | 高置信伪标签、自训练，或领域适应后微调 | 检查类别覆盖，使用独立目标域标签评价收益 |

选择一个主方案解释步骤与理由即可，例如“源域 Qwen2.5-1.5B LoRA 与零样本 LLM 起步 → 目标域文本适应或伪标签微调 → 少量人工标签用于选择和校准阈值（商品评论上零样本阈值校准的嵌套估计提高 macro-F1 1.14 个百分点）→ 独立样本评价”。完全无标签时以定性审查描述输出；获得目标域标签后，再评价准确率并校准阈值。酒店扩展与课程商品评论提交分开记录。

### i) 带噪评分：利用评分结构组织三类策略

先区分随机翻转、类别相关噪声和文本实例相关噪声，再说明评分可能同时包含产品、服务与物流体验。本项目已有可直接使用的材料：零样本 LLM 以 ≥ 95% 置信度反对标签的 92 条训练评论（1.28%），其中 57 条 TF-IDF、RoBERTa、Qwen2.5-1.5B LoRA 的 OOF 预测全部与 LLM 一致（`results/analysis/label_noise_candidates.csv`），是复核顺序与案例的来源；复核后的样本给出噪声率估计。

1. **损失与训练策略：** 比较普通交叉熵、标签平滑或噪声鲁棒损失，解释它们如何改变对单个标签的依赖；独立验证集用于选择训练轮次。
2. **样本识别与协同训练：** 讨论 confident learning、Co-teaching 等方法；本项目的标签分歧名单就是 confident-learning 式筛选的一个实例（不看标签的 LLM + 折外监督模型一致），可疑样本作为复核对象；任何过滤策略通过对照实验评估。
3. **利用评分的序数信息：** 若目标数据确实包含星级，可按评分距离中性位置的程度设置权重、构建软标签，或采用序数预测。极端评分是否更可靠仍需样本核查。

可选的小实验是在训练折注入 10% / 20% / 30% 对称噪声，保持留出折原始标签不变，比较少量有明确目的的策略，并报告负类 F1。它测量指定合成噪声下的变化，结果按注入机制解释。该实验完成前列为设计。

## 7. 可用于正式报告的文字草稿

以下草稿对应当前已保存结果（主表 seed 42，RoBERTa-base 另有 seed 2024、7）；最终提交方案改变后同步更新。方法节和表注应保留第 2 节的完整评估口径。

### 摘要草稿

英文商品评论中正类占 85.4%，总体准确率掩盖了负面评论的识别质量，而不同表示方式在这一少数类上的收益与计算代价缺少同一协议下的对照。本项目在去重后的 7,185 条训练评论和共享的五折划分上，统一比较 TF-IDF 线性分类器、GloVe 神经模型、RoBERTa / DeBERTa 编码器微调、Qwen 解码器的 LoRA 微调以及 Qwen3.8-27B 零样本分类，同时评价准确性、负类表现和计算成本。LoRA 微调的 Qwen3.5-2B-Base 以 0.28% 的可训练参数取得最高的微调指标：折均值 accuracy、macro-F1 和负类 F1 分别为 0.971、0.942 和 0.902，相对含否定标记的 TF-IDF（0.854 macro-F1，五折特征构建与拟合 1.14 秒）macro-F1 与负类 F1 分别增加 8.79 和 14.97 个百分点；不训练的 27B 零样本模型在阈值 0.5 下达到 0.940，校准阈值后 0.953（嵌套估计 0.951）。同一模型的微调与冻结特征对照（RoBERTa-base 高 7.49 个百分点，Qwen2.5-1.5B 高 11.34 个百分点）说明收益来自任务微调；RoBERTa-base 三个训练 seed 的 macro-F1 标准差 0.001 说明协议稳定。零样本模型还定位了 92 条与训练标签高置信相反的评论，其中 57 条获得三个监督模型的折外预测一致支持，为错误分析与标签噪声处理提供依据。结果为该任务提供清晰的资源选择依据：TF-IDF 适用于低成本部署，LoRA 微调的小型 LLM 适用于重视负类识别的场景，零样本 LLM 适用于无标注预算的起步。

### 主结果段草稿

LoRA 微调的小型解码器 LLM 同时在总体准确性和少数类识别上领先。与含否定标记的 TF-IDF 相比，Qwen3.5-2B-Base + LoRA 的五折 macro-F1 从 0.854 提高至 0.942，负类 F1 从 0.752 提高至 0.902；提交模型 Qwen2.5-1.5B + LoRA 为 0.940 和 0.897；两者可训练参数只占全模型的 0.28%。编码器微调处于同一方向：RoBERTa-base 0.923 / 0.868，DeBERTa-v3-base 0.934 / 0.887，三个训练 seed 下 RoBERTa-base 的 macro-F1 为 0.923、0.923、0.924。负类 F1 的增益大于 macro-F1 的增益，说明更强的分类结果由少数类识别驱动。收益来自任务微调：同一 RoBERTa-base 冻结后接逻辑回归为 0.848，同一 Qwen2.5-1.5B 冻结末 token 为 0.827，分别比微调低 7.49 和 11.34 个百分点。不训练的 Qwen3.8-27B 零样本在阈值 0.5 下 macro-F1 0.940、ROC-AUC 0.988，用训练标签校准阈值后 0.953（嵌套估计 0.951），给出本任务的测得上限；LoRA 模型以 8.7–13.8 倍更快的单模型推理达到其默认阈值水平。预训练词向量对照呈现另一层收益：GloVe 将 BiLSTM 的 macro-F1 从 0.824 提高至 0.860。结合资源测量，这些结果把五个层次的表示区分开来：稀疏特征提供秒级参照，静态预训练改善序列模型，编码器微调显著提升负类识别，LoRA 微调的小型 LLM 以 0.28% 的可训练参数（620 万 / 436 万）达到最高微调指标，27B 零样本给出不依赖标签的上限。

### 结论草稿

本项目通过统一的数据划分、嵌套阈值估计、末轮 checkpoint 对照和多 seed 复现，比较了五个层次的文本表示在不平衡商品评论分类中的实用价值。LoRA 微调的 Qwen3.5-2B-Base 与 Qwen2.5-1.5B 以 0.28% 的可训练参数取得最高的微调 macro-F1（0.942 / 0.940）和负类 F1（0.902 / 0.897），相对 TF-IDF 基线负类 F1 提高 14.97 / 14.53 个百分点；同一模型的微调与冻结对照证明收益来自任务微调。不训练的 Qwen3.8-27B 零样本达到同一水平并在校准后给出 0.953 的上限，同时定位了 92 条高置信标签分歧，为错误分析和标签噪声处理提供了直接材料。TF-IDF 以秒级成本提供 0.854 的参照。资源测量把这些收益对应到具体的训练与推理投入，为不同计算与标注预算下的模型选择提供了依据。
